# Product Description Document

## Vision
SMARTi ist eine Learn Management System App. Eltern können mit SMARTi LErnkurse für ihre Kinder erwerben und den zuweisen. Die Kinder können diese Kurse online machen, die dazugehörigen Tests machen und Skills erwerben. 


## Target Users

- Eltern von Schulkindern die Lernkurse für ihre Kinder erstellen. Eltern die Abo besitzen können Lernpfade erstellen in den Kurse oder deren Einheiten in Lernstationen verpacken.

- Kinder, die die Lernsessions nutzen um zu lernen.

- Lehrer kann über eigenen Zugang in der Plattform Kurse erstellen und anpassen oder verändern. 

- Admin führt einen Review der Kurse durch und kann diese freigeben. Er kann auch die Accounts verwalten.

## Success Metrics
_How will you measure success? (e.g., user signups, retention, task completion rate)_
- Parent-User kann sich selber registrieren, Kinder-User anlegen und verwalten. 
- Parent-User kann Kurse aussuchen, kaufen und bezahlen.
